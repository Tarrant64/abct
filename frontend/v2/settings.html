HTTPS / SSL Configuration

ABCT uses a reverse proxy for HTTPS termination. This provides better security, easier certificate management, and works seamlessly with Docker deployments.

ⓘ Recommended: Nginx Proxy Manager
  1. Point your reverse proxy to http://<container-ip>:8081
  2. Configure your SSL certificate (Let's Encrypt for public domains, or self-signed for local access)
  3. Nginx Proxy Manager web UI is typically at port 81 on your server

Alternative: Cloudflare Tunnel is also supported — see configuration below.
