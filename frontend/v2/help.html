Getting Started

1. Add Wallets

Go to the Wallets page and add your blockchain addresses. ABCT auto-detects the chain from the address format. Cardano stake addresses automatically group all related wallets.

2. Connect Exchanges

Add read-only API keys for your exchanges in Settings > API Keys. ABCT supports 42 exchanges including Coinbase, Binance, Kraken, and many more.

3. Configure API Keys

Some chains require API keys for full functionality. Free keys are available for most services. Check Settings > API Keys for the full list.

4. Explore Your Portfolio

The Dashboard shows your complete portfolio with charts, allocation breakdowns, and asset tables. Click any asset for detailed information and price charts.

Features

DeFi & Staking

Auto-detection of staking positions and DeFi protocol interactions across 80+ protocols. See your yields, rewards, and LP positions in one place.

NFT Collections

Browse your NFTs across Cardano, Ethereum, Solana, Polygon, Base, and more. Floor price valuations keep your NFT portfolio value accurate.

Transaction History

Full multi-chain transaction history with filtering, analytics, and export capabilities. Track every on-chain movement across all your wallets.

P&L Tracking

Cost basis calculation with FIFO/LIFO/Average methods. Per-asset and portfolio-wide realized and unrealized profit & loss tracking.

Privacy & Security

Token approval monitoring, address poisoning scanner, Cardano Shield threat feed, spam detection, and per-wallet privacy scoring.

Global Search

Search across wallets, DeFi positions, staking, governance, and exchange results from the top bar search.
