## Issues Resolved

### 1. Wallets Page Loading Error
**Error**: `TypeError: Cannot read properties of undefined (reading 'length')`

**Location**: wallets.html:1300, app.js:737

**Root Cause**:
- Function name collision between wallets.html and app.js
- wallets.html had renderWallets() with no parameters
- app.js had renderWallets(wallets) expecting a parameter
- app.js was loaded on wallets page, overriding the local function

**Solution**:
- Renamed renderWallets() → renderWalletsList() in wallets.html
- Updated all calls to use the new function name
- Prevents collision while keeping app.js available for shared functions

**Files Modified**:
- frontend/wallets.html (3 occurrences)

**Commit**: d81efd5
